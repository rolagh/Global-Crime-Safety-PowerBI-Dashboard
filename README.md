# Global Crime and Safety Analysis Dashboard

## Project Overview
This project analyzes global crime and safety indicators across countries using Power BI. The dashboard compares crime levels, safety levels, criminality scores, and resilience levels to help identify global patterns in crime and safety.

## Tools Used
- Power BI
- Power Query
- Excel

## Dashboard Features
- Total number of countries
- Average crime level
- Average safety level
- Average criminality score
- Average resilience score
- Top 10 countries by crime level
- Top 10 safest countries
- Countries by crime level category
- Crime vs safety level analysis
- Resistance level by country map

## Key Insights
- Countries with higher crime levels generally show lower safety levels.
- The dashboard classifies countries into crime level categories such as Low, Medium, High, and Very High.
- Some countries show strong safety levels compared to their crime indicators.
- Resistance levels vary across countries and regions.
